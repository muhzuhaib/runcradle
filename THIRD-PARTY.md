# Third-party components

Runcradle bundles open-source components, each used under its own licence: MIT, Apache 2.0, BSD and
the Mozilla Public License 2.0. The components under the Mozilla Public License are unmodified, and
each is named in the notices with its module path and version, where its source code is published.

The complete notices, with every licence text in full, ship inside the plugin itself:

```
runcradle/lib/runcradle-2026.1.0.jar  >  META-INF/THIRD-PARTY-NOTICES.txt
```

Open the jar with any zip tool to read them. They are kept with the plugin so that every copy of
Runcradle carries its notices.
